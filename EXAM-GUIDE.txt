1) ก่อนเริ่ม: เช็กเครื่องแล็บ (เปิด CMD / Terminal)
--------------------------------------------------
node -v     -> ต้องขึ้นเลขเวอร์ชัน
npm -v      -> ต้องขึ้นเลขเวอร์ชัน
git -v      -> ไม่มีก็ได้ ใช้ Download ZIP แทน

ถ้า node -v / npm -v ไม่ขึ้นเลข -> ติดตั้ง Node.js
(npm มากับ Node.js อยู่แล้ว ติดตั้งตัวเดียวได้ทั้งคู่)

  ขั้นที่ 1: เปิด nodejs.org -> กด Download -> เลือกเวอร์ชัน LTS
  ขั้นที่ 2: เลือก Windows Installer (.msi) -> ดับเบิลคลิก -> Next ไปเรื่อยๆ
  ขั้นที่ 3: ดูผล
     - ขึ้น Finish                            = มีสิทธิ์ ติดตั้งสำเร็จ
     - ถามรหัสผ่าน / ชื่อผู้ใช้ admin          = ไม่มีสิทธิ์
     - "You need administrator privileges"    = ไม่มีสิทธิ์
     - "Access denied" / error แล้วยกเลิกเอง   = ไม่มีสิทธิ์
  ขั้นที่ 4: ติดตั้งสำเร็จ -> ปิด CMD / VS Code แล้วเปิดใหม่
             -> พิมพ์ node -v และ npm -v อีกครั้ง ต้องขึ้นเลข
  ถ้าไม่มีสิทธิ์ -> ยกมือเรียกอาจารย์ / TA ทันที (ไม่ต้องแก้เอง)

  สรุป: node -v ขึ้นเลข = จบ
        ไม่ขึ้น -> ติดตั้ง .msi
        ติดตั้งไม่ได้ -> เรียกอาจารย์ / TA

อย่างอื่นที่อาจต้องโหลด:
- VS Code  : code.visualstudio.com
- โค้ดเรา  : เข้า repo บน GitHub -> ปุ่ม Code -> Download ZIP

4.5) ใส่ HTML/CSS ของอาจารย์ (อาจารย์ให้มา ขาดแค่ JS)
--------------------------------------------------
ไฟล์หน้าเว็บอยู่ที่: backend/public/index.html
(ไม่ใช่ backend/index.js ซึ่งเป็น backend)

แบบที่ 1: อาจารย์ให้มาไฟล์เดียว index.html
  -> ก๊อปทั้งหมด -> เปิด public/index.html ของเรา
  -> Cmd/Ctrl + A -> วางทับ -> Save
แบบที่ 2: อาจารย์ให้มาหลายไฟล์ (index.html + style.css ...)
  -> ลากทุกไฟล์ไปวางในโฟลเดอร์ public (ทับ index.html เดิมได้)
ห้ามลบ app.js และโฟลเดอร์ uploads

เช็ก </body>:
  </body> = ป้ายปิดส่วนเนื้อหาหน้าเว็บ (มี / = ปิด)
  โครง HTML:
    <html>
      <head> ตั้งค่า ชื่อแท็บ CSS </head>
      <body> ทุกอย่างที่เห็นบนเว็บ </body>
    </html>
  เลื่อนลงล่างสุดของ index.html หา </body>
  บรรทัดก่อน </body> ต้องมี:
      <script src="app.js"></script>
    </body>
  ถ้าไม่มี -> พิมพ์เพิ่ม
  (ต้องอยู่ท้าย เพราะเบราว์เซอร์อ่านบนลงล่าง
   ถ้าอยู่บน app.js จะหาฟอร์ม/ตารางไม่เจอ)

แก้ id ใน app.js ให้ตรงกับ HTML อาจารย์:
  หา id ใน HTML อาจารย์ เช่น <input id="productName">
  ใน app.js เปลี่ยน $("name") -> $("productName")
  ต้องเช็ก id ของ: ฟอร์ม, ช่องกรอกทุกช่อง, ช่องไฟล์, dropdown,
                    checkbox, ช่องซ่อน id, tbody ของตาราง, ปุ่มยกเลิก
  ถ้า HTML อาจารย์ไม่มี id -> ใส่ id เองในแท็กนั้น

8) Error ที่เจอบ่อย
--------------------------------------------------
xxx is not defined      -> พิมพ์ชื่อผิด ดูเลขบรรทัดใน error (index.js:43)
CORS                    -> ขาด app.use(cors())
req.body undefined      -> ขาด app.use(express.json())
                           หรือส่ง FormData แต่ route ไม่มี upload.single(...)
EADDRINUSE              -> มีเซิร์ฟเวอร์รันค้าง ปิดด้วย Ctrl + C
รูปไม่ขึ้น              -> ชื่อใน formData.append("image") ต้องตรงกับ upload.single("image")
แก้แล้วไม่เปลี่ยน       -> ลืม Save / ลืมรันเซิร์ฟเวอร์ใหม่ / ลืมรีเฟรช
404 ทุก route           -> path ขาด / ข้างหน้า เช่น "products/:id" ต้องเป็น "/products/:id"

Status code: 200 สำเร็จ | 201 สร้างใหม่สำเร็จ | 404 ไม่พบ | 400 ข้อมูลไม่ครบ
